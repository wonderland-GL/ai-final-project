# 截图目录

周报每多一个功能就多一张截图，**每周新增不超过 4 张**，否则 4 页装不下。

## 命名规范

```text
week14_01_home.png          首页 + 模板选择
week14_02_data.png          数据解析 + 单位换算
week14_03_fit.png           拟合参数 + 残差图
week14_04_ai_code.png       AI 生成初版代码的对话
week15_01_uncertainty.png   GUM + 蒙特卡洛结果
week15_02_docx.png          导出的 Word 报告
week15_03_ai_bug.png        AI 算错被纠正的对话
week16_01_mc.png            蒙特卡洛直方图 / 两模式对比
week16_02_run.png           本地成功运行（终端 + 浏览器）
week16_03_tests.png         单元测试通过
week16_04_deploy.png        另一台电脑部署成功
```

## 要求

- 截图里不要出现姓名、学号、手机号、私人聊天；
- 终端截图不要露出 Token；
- 每张图在周报里配一句"这张图证明了什么"；
- 原图放这里，周报里缩小并排。
